# Weather App

## Overview

This project is a simple weather prediction application built using Python's tkinter library for the GUI and the OpenWeatherMap API to fetch real-time weather data. The app provides essential weather details such as temperature, humidity, wind speed, and sunrise/sunset times for a user-specified location.

## Features

+ Fetches real-time weather data for any valid location.

+ Displays:

  + Current temperature (°C)

  + Weather description

  + Feels like temperature

  + High and low temperatures

  + Sunrise and sunset times

  + Humidity and pressure levels

  + Wind speed

## Dependencies

+ Python 3.7+

+ Libraries:

    + tkinter: Built-in Python library for GUI development.

    + requests: For making HTTP requests to the OpenWeatherMap API.

    + json: For parsing API responses.

    + datetime: For handling time conversions.
